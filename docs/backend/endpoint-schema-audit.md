# Rà soát API backend sau migration Cloud

> **Kiểm tra chỉ đọc 24/11/2026:** 26 kiểm tra HTTP qua Fastify injection kết nối Cloud read-only và 7 biến thể query động đều đạt status mong đợi. Danh tính dùng cho API được giả lập, chưa xác minh đăng nhập Auth thật. RLS được kiểm tra với role anonymous và authenticated trên dữ liệu hiện có; không có booking hoặc conversation để kiểm tra cách ly theo từng bản ghi. Một URL ảnh public trả 200. Không có thao tác ghi, cập nhật hoặc xóa database trong lượt kiểm tra này. AI Search được loại khỏi phạm vi theo yêu cầu.

> **Cập nhật 24/11/2026:** Cloud đã áp dụng đủ tám migration nghiệp vụ tháng 11 và các migration bổ sung đến `20261124000500`. Bucket portfolio được giữ public theo lựa chọn của người dùng. Backend đã sửa được kiểm tra với Cloud và trả 200 cho lọc genre, chi tiết photographer và portfolio mẫu. Trong lần rà soát SQL sau cập nhật, 270 câu tĩnh chuẩn bị thành công, 0 câu lỗi và 3 câu động chưa kiểm tra bằng phương pháp này. Các phát hiện bên dưới ghi nhận trạng thái trước cập nhật, không phản ánh toàn bộ trạng thái hiện tại. Kiểm thử ghi, RLS và Storage trên dự án test riêng còn chờ. Xem [tiến độ triển khai](backend-database-remediation-plan.md).

Ngày kiểm tra 24/11/2026. Đã kết nối PostgreSQL Cloud qua session pooler và áp dụng migration `20261124000100_portfolio_image_suggested_genres`. Migration được ghi vào `supabase_migrations.schema_migrations`. Constraint Cloud sau khi chạy chấp nhận 12 giá trị trong `schema (1).sql`, bao gồm `drink`, `yearbook`, `outdoor` và `tet_holiday`.

File `schema (1).sql` là snapshot tham khảo gồm `CREATE TABLE` cho các bảng đã tồn tại. Migration mới chuyển phần `suggested_genre` thành SQL nâng cấp có thể chạy trên schema hiện tại. Snapshot còn chứa nhiều trường dataset nằm ngoài các migration trong repo, nên cần giữ lại để đối chiếu tiếp. [Migration mới](../../supabase/migrations/20261124000100_portfolio_image_suggested_genres.sql) · [Snapshot người dùng cung cấp](<../../schema%20(1).sql>)

Cloud ghi nhận 8 migration MVP tháng 10 và migration mới ngày 24/11. Tám migration nghiệp vụ `20261120000100` đến `20261120000800` chưa có trong lịch sử Cloud. Migration mới chỉ xử lý `suggested_genre`. Các lỗi do schema Cloud chưa có những thay đổi nghiệp vụ vẫn tồn tại.

## Cách kiểm tra

- Đọc migration history, schema, constraint và kiểu cột trực tiếp từ PostgreSQL Cloud.
- Chuẩn bị các câu SQL backend trên Cloud bằng `PREPARE`, không thực thi các câu ghi. Trong số các câu SQL tĩnh có thể trích xuất, 216 câu chuẩn bị thành công, 53 câu báo lỗi và 3 câu động được bỏ qua. Một số lỗi cùng phát sinh từ một trường hoặc bảng thiếu.
- Đối chiếu các truy vấn lỗi với code route và service. Các endpoint dưới đây có đường thực thi gặp lỗi khi request hợp lệ đi đến truy vấn tương ứng. Kết quả không đồng nghĩa mọi request đều tới được bước đó. Chưa thực hiện đầy đủ HTTP end-to-end trên Cloud.

## Các điểm cần xử lý tiếp

- Đối chiếu tám migration tháng 11 với schema Cloud và dữ liệu hiện có trước khi chạy. Snapshot dataset trên Cloud có thay đổi ngoài repo, vì vậy cần kiểm tra từng migration và phương án nâng cấp. Không tự đánh dấu migration cũ đã chạy hoặc chạy lại các bảng gốc.
- Sau khi schema nghiệp vụ được đồng bộ, kiểm tra lại lỗi genre enum, mảng enum trong response và các thao tác ghi rồi validate response. Đây là lỗi code có thể còn tồn tại sau khi thêm cột.
- Migration mới bổ sung `suggested_genre` vào schema repo và giữ constraint như Cloud. Bảng `booking_add_ons` chưa tồn tại trên Cloud. Khi migration tương ứng được áp dụng, service tạo booking hiện lưu add-on vào snapshot nhưng chưa ghi bảng mới.
- Chưa chạy test ghi dữ liệu, test RLS hay bộ workflow trên Cloud hiện tại. Cần dùng dự án test thích hợp cho các kiểm tra đó.
