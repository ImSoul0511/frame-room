## Common endpoint rules

Every `/v1` business request except public explore, provider lists/details, tags and published portfolios requires `Authorization: Bearer <Supabase access token>`. Verify token with Supabase Auth and verified email, derive user ID server side. Path IDs and `Idempotency-Key` are UUIDs. `Accept-Language` is `en` or `vi`, default `en`. JSON request bodies use the named Zod schema in `packages/shared/src/business.ts`; reject unknown invalid input with 400. `GET`/`DELETE` have no JSON body. Return `{data: T}` with status 200 for reads/patches, 201 for normal creates, 202 for queued AI jobs, 204 for successful deletions; special POSTs may return 200 as stated in route code. Search also returns `parsedQuery`, `effectiveFilters`, `meta`; health returns `{ok:true,service:'api'}`. Errors use `{error:{code,message,details:[{reason}]}}`; use 401 unauthenticated, 403 forbidden, 404 missing, 409 conflict/stale version, 422 invalid state, 503 unavailable. Never expose raw database or provider errors.

For every path in the inventory, `:id`, `:briefId`, `:milestoneId`, `:decisionId` and `:userId` are UUID path parameters. Query parameters are route-specific: `/v1/explore` accepts `genre`, `city`, `district`, nonnegative integer `priceMax`, `page` (default 1), `pageSize` (1–50, default 20); `POST /v1/uploads` uses `bucket` and `scopeId`. `GET /v1/portfolios` and timeline/schedule filtering must be checked against the inline parser in `business.ts` before implementation. A missing filter must not expand private access.

These rows define module responsibility for every path listed in the inventory. The exact field-level request validators are the named `business.ts` schemas; the table specifications map database fields. The MVP generated OpenAPI lacks complete success schemas, so Backend Developer must publish them before Frontend handoff. Explicitly resolve response casing and query parser differences during contract review. The older v0 contract proposed direct browser upload; the MVP uses API-mediated upload.
