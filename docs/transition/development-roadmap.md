# Development roadmap

| Phase | Owner                                | Deliverable and exit check                                                                                                     | Dependency                                                              |
| ----- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------- |
| 0     | DevOps                               | Verify/push protected `archive/mvp` at full MVP SHA; agree `dev` baseline                                                      | Git review                                                              |
| 1     | Product, Frontend, Backend, Database | Freeze journeys, API shapes, identity and role rules; resolve open decisions                                                   | MVP UI and use cases                                                    |
| 2     | Frontend Developer                   | Preserve and push the complete UI on `dev`; mark endpoints awaiting implementation                                             | Shared contracts                                                        |
| 3     | Database Developer                   | Independently recreate ordered cloud schema, RLS, Storage, Auth integration; demonstrate isolation                             | Approved contract                                                       |
| 4     | Backend Developer                    | Implement validated endpoints/services and business invariants; publish machine-readable contract                              | Schema and Auth                                                         |
| 5     | AI Developer                         | Establish licensed dataset, evaluation gate, replacement AI contract and service                                               | Stable media/search schema                                              |
| 6     | DevOps                               | Remove local Supabase dependency, apply the completed pnpm setup to MVP-only scripts, and configure Cloud secrets and CI gates | Cloud setup; [pnpm handoff](../infrastructure/pnpm-without-corepack.md) |
| 7     | Whole team                           | End-to-end client/provider journey, denial cases, cost and AI quality checks                                                   | All prior phases                                                        |

Critical path: identity/profile creation → provider catalog → project/booking and scheduling → room/proofing/delivery → AI enrichment. Search needs populated portfolio images, validated embeddings, and an agreed 768-dimension model. Booking needs database locks/exclusion constraints before UI controls can be considered safe. Private media needs Storage policies and short-lived URLs. The AI redesign must resolve whether Python owns generation/embedding/culling while Fastify retains all business authorization and writes.

The MVP branch has working behavior that may be reused as reference, but it is not evidence of production readiness. Its paid AI evaluation is incomplete and the dataset is small (`plans/tasks/MVP-001-verification.md`, `fixtures/search-evaluation.json`). Do not treat the older v0 draft as the new implementation contract without reconciliation.
