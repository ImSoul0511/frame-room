# Replacement AI service contract

**Proposed, not implemented.** The Python FastAPI scaffold has only `/health`. Preserve the browser's Fastify `/v1/search`, project assistant/chat/jobs/actions interface unless a reviewed API version changes it. Fastify remains the public authorization, quota, idempotency and business-write boundary. The AI service receives scoped inputs from Fastify and returns typed results; it should not decide studio membership, booking transitions or RLS.

| Proposed internal operation              | Input                                                          | Output and failure                                                                                                                |
| ---------------------------------------- | -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `POST /internal/search/parse`            | Locale, bounded query and optional approved image reference    | Visual English description; supported genres/styles; explicit city/district/price only; validation error for unsafe/invalid input |
| `POST /internal/embeddings`              | Model version, text or normalized image descriptor, request ID | Exactly 768 finite numbers plus model/version; fail closed on mismatch                                                            |
| `POST /internal/briefs`                  | Scoped project idea, approved references, locale, constraints  | Editable brief/plan and provenance; never mark agreed                                                                             |
| `POST /internal/actions/propose`         | Authorized project/booking snapshot and allowed action kinds   | Typed proposal with explanation, source versions and required missing fields; no mutation                                         |
| `POST /internal/images/concept`, `/edit` | Prompt, permitted source image bytes/reference, request ID     | Normalized artifact bytes/reference, provenance, usage; preserve original                                                         |
| `POST /internal/cull`                    | Eligible gallery previews and selection constraints            | Ranked image IDs with reasons/confidence; no automatic client selection                                                           |
| `GET /health`, proposed `GET /ready`     | None                                                           | Liveness vs model/dependency readiness                                                                                            |

Internal requests should carry a service identity, correlation/job ID, locale, model version, timeout and idempotency key. Return stable error codes for invalid input, model unavailable, quota/timeout and uncertain provider outcome. Fastify creates/owns `ai_jobs`, `ai_usage`, `ai_actions`, artifacts and Storage writes. Do not retry a paid provider call whose outcome is unknown; preserve reservation and mark the job uncertain. Stream chat only after selecting a transport contract compatible with the MVP `POST /v1/creative-projects/:id/chat` UI message stream.

Acceptance: two-user isolation; model output schema validation; no inferred sensitive attributes in image descriptions; versioned embedding compatibility; no generated concept presented as captured photograph; action confirmation passes normal business rules; controlled cost accounting. Resolve whether the service will access Storage through short-lived scoped URLs or receive bytes from Fastify before implementation.
