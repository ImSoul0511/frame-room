# Current AI capabilities and gaps

Checked out `main` has only FastAPI `GET /health` in `apps/ai-service/app/main.py` and `fastapi`/`uvicorn` dependencies. There is no Python NLP, CV, dataset pipeline, model endpoint or Backend call to this scaffold. The fuller MVP branch keeps that same Python file while implementing AI inside TypeScript `apps/api/src/services/{ai,search,ai-jobs,ai-actions}.ts`, `worker.ts`, `repositories/ai-jobs.ts` and `routes/business.ts`.

| MVP TypeScript capability | Confirmed implementation                                                                                                                                 | Gap                                                                                      |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Search                    | Parses English/Vietnamese query or image, embeds description, filters providers, compares 768-d vectors and groups ranked images; explanations via model | `fixtures/search-evaluation.json` is small; recall/quality not validated with paid model |
| Creative assistant        | Drafts brief/plan and proposed actions; streams UI chat                                                                                                  | Requires configured Gateway key and human output review                                  |
| Concepts/edit             | Queues generated WebP artifact; preserves original on edit and marks provenance                                                                          | No assessed image quality, consent or licensed production corpus                         |
| Culling                   | Reads eligible gallery images and proposes selection                                                                                                     | Human validation and representative dataset missing                                      |
| Indexing                  | Describes portfolio image, embeds and writes `image_embeddings`                                                                                          | Model dimension pinned to 768; reindex needed if model changes                           |
| Controls                  | pgmq jobs, idempotency, project access recheck, USD reservation/settlement, unknown outcome                                                              | Operational monitoring and real-provider evaluation incomplete                           |

MVP defaults in `.env.example` name Gateway text/embedding/image models and a $30 monthly cap, but no key is committed. `plans/tasks/MVP-001-verification.md` reports `pnpm ai:evaluate` blocked by missing key and real-output review not run. `docs/adr/0004-ai-focused-mvp.md` authorized the TypeScript MVP approach at the time; the current transition request calls for an independently redesigned AI service. Treat the existing code as reference, not the target architecture.
