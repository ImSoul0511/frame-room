# Dataset and evaluation requirements

**Confirmed gap:** MVP `fixtures/search-evaluation.json` is a small test fixture, and `plans/tasks/MVP-001-verification.md` says expand to 100–200 permitted labeled images before meaningful evaluation. `apps/api/src/demo-seed.ts` seeds synthetic/demo data; it is not a curated training or evaluation corpus. No complete dataset pipeline is present in the Python scaffold.

| Dataset slice       | Required records and labels                                                                                                                                                                    | Gate                                                                                          |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Portfolio retrieval | Permitted images across portrait/fashion/wedding/family/product/food/event/cosplay, provider ID, genre, tone/setting/mood, location, publication status, relevance judgments for EN/VI queries | At least 100–200 labeled permitted images for first benchmark; separate train/eval identities |
| Visual description  | Normalized image, human description, searchable visual attributes, provenance                                                                                                                  | Avoid identity/private-attribute inference; review bias and error cases                       |
| Concept/edit        | Authorized input/reference, prompt, expected transformation, original/output provenance, human quality and safety ratings                                                                      | Consent/license and reproducible output review                                                |
| Culling             | Gallery sets, client selection constraints, expert preference/rationale and diverse lighting/quality cases                                                                                     | Measure ranking agreement; retain human final choice                                          |
| Language            | Parallel English/Vietnamese prompts, expected intent/filter extraction and answer quality                                                                                                      | Verify default English and explicit Vietnamese selection                                      |

For every asset record `source`, `collected_at`, `license_note`, consent/use scope, deletion request handling, checksum, split, labeler and model version. Do not include personal contact data. Track exact embedding model and dimension per vector; changing model requires reindexing, not mixing vectors in one comparison. Evaluate recall@K, precision@K, provider diversity, filter accuracy, latency and cost; review concept/brief/cull/edit outputs with human raters. Establish pass thresholds with product/AI owners before enabling broad use. The MVP's missing Gateway key means real model quality has not yet been measured.
