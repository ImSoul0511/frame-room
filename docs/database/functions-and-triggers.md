# Functions, triggers and view

Source: MVP SQL migrations in `supabase/migrations/` on the feature branch. Preserve creation order and grants.

| Object                                                                                                                                                              | Confirmed purpose                                                                                                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `public.uuid_generate_v7`                                                                                                                                           | Generates business UUIDv7 IDs; `profiles.id` remains Auth UUID.                                                                                      |
| `private.is_admin`, `is_manager`, `owns_provider`, `provider_visible`, `provider_side`, `can_read_booking`, `can_read_project`, `can_read_room`, `can_read_gallery` | RLS authorization predicates.                                                                                                                        |
| `private.touch_updated_at` plus per-table `touch_updated_at` triggers                                                                                               | Sets update timestamp on mutable rows.                                                                                                               |
| `private.require_manager` trigger                                                                                                                                   | Rejects loss of last studio manager.                                                                                                                 |
| `private.reserve_booking`; `public.frameroom_transition`, `frameroom_reschedule`                                                                                    | Lock booking/studio, reserve assignee/resources and enforce state/version in one transaction.                                                        |
| `private.prevent_assigned_departure` trigger                                                                                                                        | Rejects departure of actively assigned studio photographer.                                                                                          |
| `private.check_schedule_consistency` deferred constraint triggers on bookings/schedule entries                                                                      | Ensures booking schedule and reservation rows agree at transaction end.                                                                              |
| `public.frameroom_reserve_usage`                                                                                                                                    | Serializes monthly AI spend reservations; later migration adjusts settlement/limit logic.                                                            |
| `public.frameroom_enqueue_job`, `frameroom_claim_jobs`, `frameroom_archive_job`                                                                                     | pgmq worker queue lifecycle; service-role execution only.                                                                                            |
| `private.storage_read`                                                                                                                                              | Checks private Storage object access by owner, project, booking/room and state.                                                                      |
| `public.providers` view                                                                                                                                             | Security-invoker union of visible photographers and studios with price/rating aggregates; introduced in migration 3 and updated after array changes. |

Later migrations modify assignment serialization (`00500`), budget settlement (`00600`), project concept selection (`00700`) and demo daily AI limit (`00800`). Read the actual SQL bodies when writing replacement scripts; a first-migration-only copy will miss these invariants. The initial migration adds room messages, decisions, milestones and AI jobs to `supabase_realtime` publication. Recheck publication and replication permissions in Cloud.
