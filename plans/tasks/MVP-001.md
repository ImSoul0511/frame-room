# MVP-001: AI-focused course-demo application

Status: In Review; real-AI release evaluation pending credentials and dataset
Owner: Implementation assistant, at the user's request

## Goal and scope

Implement the user-approved AI-focused MVP: creative projects, discovery, concepts,
brief planning, studios/resources, transactional booking, collaboration, proofing,
AI culling/editing, confirmed actions, delivery, reviews, and moderation.

The user approved implementation of the complete plan on 2026-10-30. This supersedes
foundation-only AI deferral and authorizes the proposed defaults, not a claim that
the named team reviewers have reviewed this change. Work branches from AGENT-001
to preserve its unmerged foundation; no protected branch is modified or merged.

## Decisions

- Explicit verified-user profile creation; read-only GET /me; preserve Auth IDs.
- Current client, assigned photographer, and relevant managers access booked projects.
- No fees, automatic completion, RAW processing, payments, or deployment.
- Controlled tags; mandatory generated/edited provenance; original files retained.
- Authenticated AI; 24-hour temporary references; bounded jobs and monthly spend.
- User amendment: English is the default UI/AI language; Vietnamese is selectable.
  Persist the selection in local browser preferences, with matching dictionaries,
  locale-aware formatting, and no automatic browser-language override.
- PostgreSQL is authoritative. Missing services return actionable errors, never fake success.

## Acceptance criteria

- [x] Complete browser-to-database client/provider journey.
- [x] Role, booking overlap, state, stale action, and media isolation checks.
- [ ] Persistent AI jobs, validated output, usage accounting, explicit confirmation.
- [x] Local checks and reproducible migration/type-generation evidence.
- [ ] AI retrieval evaluation and real-provider human review, when credentials exist.
