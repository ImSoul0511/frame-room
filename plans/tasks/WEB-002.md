# WEB-002: Photography discovery and account interface

Status: In Review

Scope: Existing pages only; preserve the lavender, paper, blue, sage and gold palette.
Remove browser demo state and disconnected components. Present real portfolio photographs,
descriptions and database taxonomy with paginated search and sorting. Add watercolor botanicals,
subtle motion, scroll reveals, larger typography, natural image framing and genre introductions.
Introduce the existing Shoot Brief workflow without adding routes. Connect the account calendar,
notifications and image-tag editor to implemented APIs.

Contract impact: Add optional `q` and `sort` to the public portfolio query and optional assigned
tags to list responses. Preserve authorization, database schema and existing route identifiers.
See [MVP contract](../../docs/api/mvp.md). No database writes or deployment are part of this task.

Validation: TypeScript, ESLint, documentation checks and production build passed. The full
Vitest suite passed with 264 tests using limited workers. Ten browser checks passed,
covering 375px/1280px layout, taxonomy completeness, image loading, pagination, keyword/sort requests,
language persistence and unsigned account redirects. Read-only API checks confirmed 159 active
tags across 11 categories and matching assigned tags on filtered collections.

Limit: Authenticated calendar, notifications and image-tag writes need an account session for
end-to-end verification. Product pages use the real Auth client and API; isolated browser fixtures
are used only in tests, without account credentials or database writes.

Header and framing refinement: Show both language names in full. The avatar opens the installed
Astryx DropdownMenu with Profile and Sign out; the existing Settings route is a tab inside the
profile workspace. Search focus keeps the typing caret without an outline or glow. Photo frames,
albums, lightbox and provider covers retain the full image ratio with smaller intro overlap.
Three browser checks cover language labels, focus styling, keyboard menu dismissal, profile/settings
navigation, sign-out through an intercepted Auth response and real image/frame dimensions.
The sign-out check verifies client behavior with an isolated session, not a real account journey.

Explore composition: Bound photographs in both dimensions while retaining their aspect ratios;
intro frames stay within 440px by 420px, collection images within 420px by 360px, gallery images
within 480px by 420px and profile covers within 960px by 340px. Viewport-based limits reduce
heights on smaller screens. Smaller hero and template flowers leave space for the primary copy.
The shared fitted image component reserves a nonzero frame during lazy loading, then sizes it
from the loaded image ratio; this prevents narrow collapsed frames on mobile.
Soft gradients blend existing paper, lavender and surface tokens across section boundaries.
Independent scroll reveals, staggered cards, heading highlights and a single CTA glow emphasize
the main actions. Reduced-motion mode keeps all content visible without animation.

Botanical refinement: Shared SVG joints keep petals attached to the animated stem. Staggered
stem, neck and petal motion replaces the rigid sway; stronger watercolor shading and a small
flower cluster retain the palette. The latest supplied reference supersedes the earlier
three-petal constraint: broad, scalloped petals overlap into a fan, painted from a light rear
layer to a dark foreground layer. Mottled pigment, loose outlines and small calyx leaves follow
the reference. The left wash uses one shape. A browser regression
verified attachment at four animation times, visible displacement, reduced motion and mobile fit.
