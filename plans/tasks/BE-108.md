Status: In Review
Owner: Khai

## Scope and dependencies

Implement and verify the P2 studio aggregate dashboard, user content reporting,
and admin moderation endpoints on top of BE-101/102/105:

- Studio dashboard: `GET /v1/studios/:id/dashboard`.
- Content reports: `POST /v1/reports`, `GET /v1/admin/reports`,
  `PATCH /v1/admin/reports/:id`.
- Admin moderation: `POST /v1/admin/moderation`.

No new SQL migration or Cloud deployment is included in this slice.

## Acceptance

- [x] Shared Zod schemas (`reportInputSchema`, `moderationInputSchema`) and OpenAPI
      registration aligned for all 5 BE-108 endpoints.
- [x] Studio dashboard enforces studio manager authorization (`403` for non-managers) and
      returns booking stats, upcoming schedule, and active studio resources.
- [x] Any verified user can submit reports for supported target types (`portfolio`,
      `portfolio_image`, `photographer`, `studio`, `review`, `message`).
- [x] Admin report listing/resolution and moderation actions enforce `private.is_admin()`
      (`403` for non-admins).
- [x] Moderation updates `portfolios.status` (`hidden` / `draft`) and `is_hidden` on
      other target tables.
- [x] Local route integration tests recorded in [verification](BE-108-verification.md).
- [ ] Real Cloud database/RLS integration verified (deferred).
- [ ] Independent reviewer acceptance recorded.

## Handoff
